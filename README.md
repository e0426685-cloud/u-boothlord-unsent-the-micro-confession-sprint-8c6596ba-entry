A two-part micro-confession, 135 characters: a To: line and the one line typed to a brother and never sent — a childhood bike, blamed neighbours, and an apology twenty years late. Specific, honest, and kept in drafts because it was too late to say it out loud.

## Run it

```sh
python3 main.py
```

This writes the confession to `/output/entry.txt` (UTF-8, 1–260 characters, mode 0644 so the grader can read it).
